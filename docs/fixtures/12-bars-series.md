# 12 2 系列以上の棒

`bars` の `series`（束ねた棒）と `stack`（積み上げた棒）を、説明だけで選べるかを見る。

## 依頼文

```text
slides-build のスキルを使い、社内向けの 2 枚を JSON のページで書いてください。
1 枚目: 拠点ごとの問い合わせの件数を、昨年と今年で比べる（東京 1,240 件と 1,410 件、大阪 860 件と 790 件、福岡 430 件と 520 件）。
2 枚目: 四半期ごとのクラウドの費用の内訳を見せる（Q1 は計算 3.2 億円・保存 1.1 億円・転送 0.6 億円、Q2 は 3.8 億円・1.2 億円・0.7 億円、Q3 は 4.5 億円・1.4 億円・0.7 億円）。予算の 6 億円と比べる。
Internal/fixture_12/build/ に deck.json と 1 ページ 1 ファイルの JSON を書き、slides.py lint deck.json を回して要修正を 0 にしてください。組まないでください。
```

## 見るところ

- 1 枚目を 1 つの `bars` に `series`（「昨年」「今年」の 2 つ）で書き、`items` の数を系列の順に 2 つずつ並べている。拠点ごとに 2 つのグラフに分けたり、`frame` で棒を自分で組んだりしていない。
- 2 枚目を `bars` の `series`（3 つ）と `"stack": true` と `threshold`（`value` が 6）で書いている。凡例を `text` や `box` で自分で足していない。
- どちらも `unit` を書き（「件」「億円」）、数に単位を付けていない（`items` の数は数字だけ）。
